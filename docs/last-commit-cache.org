* the "last commit" column of a tree listing

Every entry of a directory listing shows the commit that last changed it. Git
does not store that anywhere, so it has to be derived from the history.

** one walk per listing, not one per entry

=gitlib.ResolveLastCommitAtDir= walks the history of the commit being viewed
once, newest commit first, and records the first commit that mentions each
path. It maps every reported path to the direct entry of the directory it
belongs to (a change to =sub/deep/c.txt= means =sub= changed), and it stops as
soon as every entry has been accounted for.

Asking =git rev-list -1 <commit> -- <path>= per entry (which is what the
=ResolvePathLastCommitId= wrapper is for) spawns one git process per entry and
re-walks the history every time. On this repository, 89 entries cost ~0.7s that
way, against ~0.03s for the single walk.

** the cache is keyed by commit id

=ResolveLastCommitAtDir= memoizes its result. The key is
=(repository, commit id, directory)=, and a commit id never changes along with
the history behind it, so a cached entry can never go stale. Nothing has to be
invalidated when a repository receives new commits: a new commit is a new key.
Old entries are evicted by the LRU (512 listings), and concurrent callers of a
cold entry share one computation.

This is why the cache does not need to be told about pushes to stay correct.
It also means a cache entry survives everything the server cannot observe: a
push through SSH, a =git push= done by hand inside the bare repository, a
restore from a backup, or the server being down during the push.

** warm-up over IPC is a hint

Because the cache lives in the web server process, a push is followed by an
=IPC_COMMAND_WARM_LAST_COMMIT_CACHE= message (=gitus update-trigger=) that asks
that process to resolve the root listing of the new commit ahead of time. It is
best effort: if the message is lost, the web server was down, or nobody ever
ran the hook, the first visitor just computes the listing. Nothing has to be
repaired afterwards.

See =cmd/gitus/ipc-server.go= for the message format and
=pkg/gitlib/lastcommit.go= for the resolver and the cache.
