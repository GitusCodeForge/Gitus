* config

for details, please visit file ~pkg/gitus/config.go~.

** debug mode

=debugMode= (=false= by default) makes the error page show internal error
messages: the raw text of a failed database query, a file that could not be
opened, and so on. It is meant for development, and for debugging a live
instance when the error is not reproducible elsewhere.

When it is off, the visitor only sees

#+begin_example
Internal error: An unexpected error occurred. Please contact the administrator and mention reference 51b9ea7f.
#+end_example

and the full message goes to the server log with the same reference:

#+begin_example
2026-10-27T11:56:48+08:00 ERROR [INTERNAL ERROR] 192.0.2.1:1234 GET /somewhere (ref 51b9ea7f): open /srv/git/secret.git/config: permission denied
#+end_example

The flag is toggled in the site settings (=/admin/site-config=, "Basic
Settings"). It is never enabled by default, and it should stay off on any
instance that other people can reach: internal messages may contain absolute
paths, SQL errors and library versions.

** log level

=logLevel= (=info= by default) is one of =info=, =warn=, =error= or =none=.

- =info= writes everything, including the per-request lines and the startup
  messages;
- =warn= hides =info= and keeps warnings and errors;
- =error= keeps only errors that prevented an operation from completing;
- =none= turns the log output off.

An empty value means =info=, so a configuration file written for an older
Gitus keeps working. An unknown value also falls back to =info= and logs a
warning, so a typo cannot silence the server by accident. See
[[file:logging.org][logging]] for the levels and the recommended usage.

** maintenance announcement

=maintenanceAnnouncement= schedules an announcement before a maintenance
window. the site keeps running and shows a banner until =startsAt=; at that
time the effective mode becomes =mode= (=shutdown= by default). it returns to
=globalVisibility= at =endsAt= only when =autoRestore= is enabled. see
[[file:maintenance.org][maintenance]] for the timeline and the difference
between =shutdown= and =maintenance=.

** commit message tags

=commitMessageTags= maps a tag (a line of its own in the commit message) to the
behaviour it requests. The built-in behaviours are =no-webhook=, which skips
the webhook of the push that contains the commit, and =no-ci=, which only marks
the commit in the webhook payload because Gitus has no CI runner. When the
field is not mentioned at all, ={"!no-webhook": "no-webhook", "!no-ci":
"no-ci"}= applies; ={}= turns every tag off. See
[[file:commit-message.org][commit message]].

** http clone

=gitConfig.httpCloneProtocol.v1dumb= and =gitConfig.httpCloneProtocol.v2=
switch the two HTTP clone protocols on and off; see
[[file:http-clone.org][http-clone]] for what they are.

=gitConfig.maxConcurrentClone= (=8= by default) is the maximum number of HTTP
clone requests that may run =git upload-pack= at the same time. A request
over the limit gets =503 Service Unavailable= with =Retry-After: 1=. =0= also
means the default. This bounds the process/fork cost of a burst of clones; it
does not make a very large public repository cheap to clone.

** database type

=database.type= is one of =sqlite=, =postgres=, =mysql= or =mariadb=.
=mysql= and =mariadb= use the same backend, so either spelling works against
either server.

For =postgres=, =mysql= and =mariadb=:

- =database.url= is =host:port= of the server (e.g. =127.0.0.1:3306=);
- =database.userName=, =database.password= and =database.databaseName= are the
  credentials and the schema to use;
- =database.tablePrefix= is prepended to every table name, so several
  instances can share one database.

The database must already exist; Gitus creates its tables inside it when the
instance is installed (and =EnsureSchema= adds tables/indexes introduced by a
newer version on startup).
