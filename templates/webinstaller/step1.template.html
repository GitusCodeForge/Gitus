Step 1

Gitus supports 3 different operation mode.:

  • Browse-Only Mode: A simple Git web frontend similar to git-instaweb. Repositories would be readonly (with HTTP).
  • Host Mode: User and repository managements are done by updating special repositories similar to Gitolite. Clone/push through SSH is enabled.
  • Forge Mode: All features enabled (other than the ones you choose to not enable).
