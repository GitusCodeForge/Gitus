SSH Authentication
AuthorizedKeysCommand makes sshd call gitus authorized-keys for every login attempt; disable AuthorizedKeysFile in sshd_config or sshd will consult the file first. The external command (an absolute path) is run with the SSH username and the offered key or fingerprint, and must print authorized_keys lines. Fixed arguments can be set with sshAuth.args in the config file.
